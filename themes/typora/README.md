# Shittori · Typora

暖纸白与松叶绿的浅色主题，以及深蓝灰的「蓝夜」。以中文长文为主，兼顾英文笔记；标题、正文和代码保留墨色，强调色用于链接、高亮和提示。

[项目主页](https://github.com/ishixi233/shittori) · [下载主题包](https://github.com/ishixi233/shittori/releases/tag/typora-1.0.0)

## 安装

1. 下载并解压 `Shittori-Typora.zip`。
2. 在 Typora 的偏好设置中打开主题文件夹，将 `shittori.css`、`shittori-night.css` 和整个 `shittori/` 文件夹复制进去，保持目录结构。
3. 重启 Typora，在「主题」菜单选择 Shittori。它会跟随系统深浅色；若希望固定深色，选择 Shittori Night。

## 字体与调整

主题不下载或附带字体。中文正文优先使用思源宋体 VF，英文正文使用 Source Serif 4；一级标题使用方正大标宋简体与 EB Garamond，强调使用霞鹜文楷，代码使用 JetBrains Mono。没有这些字体时会使用后备字体，仍可正常阅读。方正字体需自行确认使用许可。

常用颜色和字体变量位于 `shittori.css` 开头，深色颜色位于 `shittori/dark.css`。正文默认左对齐，加粗只增加字重。完整字体表和调整方法见[项目说明](https://github.com/ishixi233/shittori#依赖的字体)。
